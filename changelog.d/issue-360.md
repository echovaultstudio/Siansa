### Changed
- Musix is now **Siansa**. Siansa installs as a new app next to the old one: to bring over your settings, vibes and history, make a backup in the old app (Settings › Backup) and restore it in Siansa, then uninstall the old app.
- The AudioMuse-AI plugin is now **Siansa Analysis**. Install it before removing the old Musix Analysis plugin: it copies everything already measured, so nothing is measured again. Until then, Siansa keeps using the old plugin.

Open source

Siansa is free software, under the GNU General Public License, version 3 or later. We believe an app that holds your server login should be open to read, and that music players for self-hosted servers are better built together. The code is on GitHub, and so is the AudioMuse-AI plugin (AGPL 3). Bug reports and pull requests are welcome; the beta testers repository has the docs and the issues.

It's built on open-source software too. These are the libraries inside the Android app, and their licences. Thank you to everyone who makes them.
